1. Machine Learning × Aviation: Turbofan Engine Fault Risk Prediction

Physics-Informed Feature Engineering and Multi-Model Fusion for Turbofan Engine Fault Risk Prediction

Background: Predictive maintenance of turbofan engines is a core challenge in Aviation Industry 4.0. While machine learning methods have become mainstream, they still commonly suffer from homogeneous feature engineering and the difficulty of balancing prediction performance with interpretability.

Research Content:

  1. Data Preprocessing: Comprehensive statistical analysis including outlier handling, missing value imputation, and feature encoding.

  2. Physics-Informed Feature Engineering: Constructed features based on gas turbine thermodynamic principles to characterize engine degradation mechanisms, including lifecycle stage discretization, thermodynamic ratios (pressure ratio, temperature ratio), and other advanced features.

  3. Class Imbalance Handling: Implemented SMOTE and other oversampling strategies within a cross-validation framework.

  4. Model Training & Evaluation: Bayesian optimization for efficient hyperparameter tuning across multiple ML models, with 5-fold cross-validation and threshold search for improved classification accuracy.

  5. Interpretability Analysis: Introduced SHAP framework at both global and individual levels for the best-performing single model.

  6. Engineering Application: Built weighted fusion (F1-score power-based) and Stacking ensemble strategies for improved generalization.

Key Results:

  • GBDT achieved optimal performance: ROC-AUC = 99.24%, F1-score = 85.19%

  • SHAP analysis revealed that lifecycle stage discretization, cumulative operating cycles, and high-pressure compressor outlet static pressure are the key factors driving fault risk

  • Validated the effectiveness of integrating thermodynamic principles into feature engineering

Innovation Highlights:

  • Transformed gas turbine performance theory into computable features (pressure ratio, temperature ratio, lifecycle stage transitions), breaking through the limitations of purely data-driven feature engineering

  • Used SHAP results for reverse validation of feature design consistency with domain knowledge

  • Consciously distinguished between scientific interpretation and engineering prediction objectives

2. Deep Learning × Computer Vision: Aerial Image Object Detection

Align-Det: End-to-End Real-Time Small Object Detection in Aerial Images

Background: Small object detection in aerial images suffers from low accuracy and poor real-time performance. Based on YOLOv8, we designed Align-Det, an end-to-end real-time detector for high-resolution aerial images, targeting resource-constrained embedded flight devices.

Core Innovations:

  1. Feature Complementary Mapping Module (FCM): Transfers shallow spatial position information to deep semantic features, mitigating small object information loss during downsampling through a channel-spatial bidirectional complementary mapping mechanism.

  2. Multi-Kernel Perception Unit: Employs multi-scale convolution kernel cascade structure (3×3, 5×5, 7×7) to enhance perception capability for objects at different scales.

  3. Network Lightweight Design: Redesigned downsampling strategy (group convolution followed by channel expansion), reducing parameters by 18% and computation by 11% compared to baseline.

Experimental Results:

  • Evaluated on VisDrone, UAVDT, and AI-TOD benchmarks

  • Compared to YOLOv8 series: 66-74% parameter reduction with 1.2-2.3% accuracy improvement

  • Align-Det performance surpassed several SOTA methods

  • Ablation studies validated the rationality and effectiveness of each module

Output: Accepted for presentation at IJCNN 2026 (IEEE WCCI 2026). Available as preprint on arXiv.
